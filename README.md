# analisiscartera
Dashboard que explica la cartera para su análisis. 
Base de datos modificada con información crediticia. Contiene variables clave como regional, rubro, destino, CAEDEC, calificación y días de atraso. Diseñada para un aplicativo web que genera dashboards descriptivos y modelos predictivos (regresión lineal múltiple) para evaluar el riesgo y estado de la cartera.
